# Jewellery photos (optional)

The app ships with its own vector jewellery illustrations. To use real photography, drop optimised
images here using these exact names - then list them in `manifest.json` (e.g. `{"ring": "ring.jpg", "necklace": "necklace.jpg"}`) and they replace the illustrations automatically (no code change):

ring.jpg  necklace.jpg  earrings.jpg  bangle.jpg  chain.jpg  pendant.jpg  mangalsutra.jpg  coin.jpg  diamond.jpg  gem.jpg  pearl.jpg

Recommended: 800x600 (4:3), JPEG/WebP under 120 KB, clean background, soft studio lighting.
Only use photos you own, generated yourself, or that are licensed for commercial use.
